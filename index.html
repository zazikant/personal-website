How It Works

From messy PDFs to answers you can cite in 30 seconds.

No model training, no fine-tuning, no infrastructure to babysit. Drop a document in, ask a question, get an answer with the source file attached.

01 / INGEST

Drop a document in

Upload a PDF, markdown, or raw text. We handle the parsing — no cleanup, no formatting fixes needed on your end. Every chunk is tagged with its filename, doc_type, project, and version so you can filter later.

You get: Drop a 200-page PDF, we handle the parsing.

POST /api/upload · /api/ingest
02 / INDEX

We remember where every fact came from

Each document is chunked, embedded, and stored with full provenance — filename, version, page, and upload timestamp. So v2 of a policy doesn't get mixed with v1, and retrieval can be scoped to a single project or release.

You get: We remember which file, version, and page each fact came from.

NVIDIA embeddings · Pinecone
03 / ANSWER

Ask a question, get a cited answer

Query expansion catches synonyms automatically — "owner" matches "lead" and "manager". An LLM reducer synthesizes the most relevant chunks into one coherent answer, detects conflicts across sources, and lists every filename it used.

You get: One answer + a list of source files. No made-up filler.

POST /api/query · /api/query-stream
API Reference

Agentic first. Built for AI agents to call directly.

Every endpoint is a simple REST call — no SDK, no auth headers beyond a bearer token, no pagination. Point your agent at the base URL and let it ingest, query, and manage documents autonomously. Base URL: https://doquerag.vercel.app

File size limit: PDF uploads must be under 4.5 MB (Vercel serverless payload limit). For larger files, split before upload or use the raw text ingest endpoint.
POST /api/query 
# Ask a question — conversational mode (top-K = 12)
curl -X POST "https://doquerag.vercel.app/api/query" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What is the architecture?",
    "mode": "conversational"
  }'

# Response
{
  "answer": "The synthesized answer...",
  "sources": ["doc1.md", "doc2.pdf"],
  "aggregatedContext": "Key Points: ...",
  "debug": {
    "hitsFound": 7,
    "documentsAggregated": 3,
    "reducerUsed": true
  }
}
